SharePoint Folder Scan

SSH commands

Use nohup ... & so the scan keeps running if your SSH session closes. 

# Azure Portal → App Service → SSH, then:
cd {{ ssh_app_dir }}
nohup {{ ssh_python }} manage.py scan_folders > /home/LogFiles/scan_folders.log 2>&1 &
# Scan AND fix misplaced paths in one go:
nohup {{ ssh_python }} manage.py scan_folders --apply > /home/LogFiles/scan_folders.log 2>&1 &
# Fix paths later, from the last completed scan:
{{ ssh_python }} manage.py fix_folder_paths --all --dry-run
{{ ssh_python }} manage.py fix_folder_paths --all
{{ ssh_python }} manage.py fix_folder_paths --contract-id 1234
# A scan stuck as "running" after a dropped session:
{{ ssh_python }} manage.py scan_folders --force
