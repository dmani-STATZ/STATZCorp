You can now add a National Stock Number without leaving the NSN Portal or the New CLIN form.

- **NSN Observatory** has a **+ Create NSN** link next to the search box. If a search finds no catalog row, you can create one from the empty results page (the code is prefilled when the search looks like an NSN).
- After you save, you land on that NSN's dossier page.
- On **New CLIN**, the NSN picker has **+ Add new NSN**. Create and select in one step — no need to leave the form.
- The system will not create a second row when the same NSN (with or without dashes) already exists. If you are editing an older duplicate record, fixing its description still saves.
