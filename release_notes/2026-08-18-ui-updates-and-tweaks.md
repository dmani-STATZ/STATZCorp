**UI Tweaks** Updates the functions.

## What's New

General polish across the interface, some function updates under the hood, and a
handful of small things we're not going to spell out.

We'll say this much: not every feature ships with a menu item. Some of them are
just *there*, waiting for someone impatient enough to find them.

If something in this build looks purely informational — the kind of small text in
the upper right that you'd normally read once and never touch again — consider
that we don't put things on screen for no reason. Read it. Then don't stop at
reading it.

Persistence helps. So does speed. One poke does nothing. Five gets you somewhere,
provided you don't take longer than ten seconds about it — the app stops counting
after that and you start over.

Everything else in this release behaves exactly as you'd expect. This part doesn't.
