## What Changed
In the Mailbox, PDF and image attachments now have a **View** button. It opens the file in a panel next to the message, in the same window, so you can read a supplier's quote sheet while you enter it. Attachments of other types (Word, Excel and so on) still download as before.

## What You'll Notice
- Drag the divider to resize the panel. It remembers the width you leave it at.
- If a message has several PDFs or images, tabs across the top of the panel switch between them. The arrow icon opens the file in its own browser tab; the X closes the panel.
- Once you open the panel it stays open as you move from message to message, until you close it.
- With the panel open you can also open **Log supplier quote**. The drawer now sits beside the message and the attachment instead of covering them, and the inbox list steps out of the way while all three are showing.
- On a narrow window the attachment appears below the message instead of beside it.

## Action Required
None.
