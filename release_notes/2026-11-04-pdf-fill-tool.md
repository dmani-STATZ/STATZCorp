PDF tools now has a Fill PDF page. Open a form, click where you want to type, and use ✕ Mark for checkboxes. Drag a box by its grip if it needs to move.

Save filled PDF downloads `<name>_filled.pdf`. The file stays small because the text is written onto the original, not printed into a new one.

You can change the boxes and save again. Each save starts from the PDF you uploaded, so the file does not grow every time.

Stop using Microsoft Print to PDF for these forms.
