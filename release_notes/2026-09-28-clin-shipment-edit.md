## What Changed
Each row in **Shipping Information** on the CLIN page now has an **Edit**
button (the pencil, next to Save and Delete). It opens the same window as
**Add New Shipment**, already filled in, so you can change the shipment name,
quantity, UOM, ship date or comments in one place.

Quote Value and Item Value recalculate automatically when you change the
quantity. The CLIN's Ship Qty and Ship Date update when you save.

## What You Need To Do
Nothing. **Paid** and **Customer Pay** can't be changed from the Edit window.
Keep entering those as payment history entries so the totals stay accurate.
POD Date is still set with the **POD** button on the row.
