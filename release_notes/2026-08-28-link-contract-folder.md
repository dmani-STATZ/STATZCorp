Contract pages now include a **Link Contract** option for connecting a contract to an existing SharePoint folder.

Copy the folder path from File Explorer's address bar and paste it into the new dialog. STATZ verifies that the folder exists in SharePoint before saving it. Invalid paths stay in the dialog so they can be corrected, and successful changes are included in the contract audit trail.
