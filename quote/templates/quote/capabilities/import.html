What gets picked up

  • NSN 13 digits, any hyphenation: 5340-01-234-5678, 5340012345678
  • FSC a bare 4-digit class: 5340 matches every NSN in it
  • Anything else in an NSN column (a 9-digit NIIN, a number a digit short) is listed as unreadable so you can fix it.

Several suppliers in one file

We look for the supplier column by comparing your cells with the supplier directory: a column of CAGEs or names we recognise. You can change any column before importing.
